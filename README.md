## 3.1. User Stories


| Epic / Story ID | Título | Descripción | Criterios de Aceptación |
|-----------------|--------|-------------|------------------------|
| US01 | Visualización de Niveles EM | Como usuario, quiero visualizar en tiempo real los niveles de contaminación electromagnética en mi zona, para saber si es seguro permanecer ahí. | **Escenario 1:** Dado que el usuario tiene sensores activos vinculados a su cuenta, Cuando accede a la sección de monitoreo en la app móvil, Entonces el sistema muestra los niveles actuales de radiación con actualización automática e indicador visual de nivel (bajo, medio, alto). **Escenario 2:** Dado que el usuario no tiene sensores vinculados a su cuenta, Cuando accede a la sección de monitoreo, Entonces el sistema muestra un mensaje "No tienes sensores vinculados" y un botón para contactar soporte. **Escenario 3:** Dado que un sensor vinculado se encuentra desconectado, Cuando el usuario visualiza el monitoreo, Entonces el sistema muestra la última lectura registrada con una etiqueta "Última lectura: [fecha/hora]" y un indicador de sensor offline. |
| US02 | Alertas Automatizadas | Como usuario, quiero recibir alertas automáticas cuando los niveles EM superen los límites recomendados, para poder actuar a tiempo. | **Escenario 1:** Dado que los niveles de radiación superan el umbral de seguridad configurado, Cuando el sistema detecta la lectura elevada, Entonces envía una notificación push al usuario indicando el nivel detectado, la zona afectada y la hora del evento. **Escenario 2:** Dado que un usuario no tiene activadas las notificaciones, Cuando los niveles EM superan los límites, Entonces el sistema registra el evento en el historial sin enviar alerta push. **Escenario 3:** Dado que los niveles de radiación vuelven a estar dentro del rango seguro, Cuando el sistema detecta la normalización, Entonces envía una notificación al usuario indicando que los niveles han vuelto a la normalidad. |
| US03 | Recomendaciones Personalizadas | Como usuario, quiero recibir recomendaciones según mi historial de exposición, para reducir riesgos en mi entorno. | **Escenario 1:** Dado que el usuario tiene al menos 7 días de datos de exposición registrados, Cuando el sistema analiza su historial, Entonces muestra recomendaciones específicas basadas en sus patrones de exposición. **Escenario 2:** Dado que el usuario no tiene suficiente historial registrado, Cuando el sistema intenta generar recomendaciones, Entonces se muestra un mensaje indicando que no hay suficiente información disponible y ofrece recomendaciones generales. |
| US04 | Control automático de dispositivos por alta radiación | Como usuario, quiero que el sistema apague automáticamente los dispositivos cuando detecte un nivel alto de radiación, para proteger los equipos y evitar daños en el sistema. | **Escenario 1:** Dado que el sistema detecta un nivel de radiación superior al límite permitido, Cuando se activa la alerta, Entonces el sistema apaga automáticamente los dispositivos conectados mediante el adaptador inteligente y registra el evento. **Escenario 2:** Dado que se ha ejecutado el apagado automático, Cuando el proceso finaliza, Entonces el sistema envía una notificación al usuario indicando qué dispositivos fueron apagados y el motivo. **Escenario 3:** Dado que el sistema intenta apagar un dispositivo pero el adaptador inteligente no responde, Cuando falla la comunicación, Entonces el sistema registra el error y notifica al usuario que el apagado no pudo completarse. |
| US05 | Configuración de apagado opcional | Como usuario, quiero poder activar o desactivar el apagado automático de dispositivos, para tener control sobre cómo responde el sistema ante niveles altos de radiación. | **Escenario 1:** Dado que el usuario accede a la configuración de apagado automático, Cuando activa la opción, Entonces el sistema guarda la preferencia y la aplica ante futuras situaciones de radiación elevada. **Escenario 2:** Dado que el usuario ha desactivado el apagado automático, Cuando se detecta una alerta de radiación elevada, Entonces el sistema solo notifica al usuario sin apagar los dispositivos. |
| US06 | Visualización de recomendaciones para cuidado de dispositivos | Como usuario, quiero ver recomendaciones sobre el cuidado de mis dispositivos, para prevenir daños causados por radiación u otros factores ambientales. | **Escenario 1:** Dado que el usuario accede a la sección de recomendaciones de dispositivos, Cuando ingresa al módulo, Entonces el sistema muestra una lista de recomendaciones actualizadas sobre el cuidado y ubicación óptima de sus dispositivos. **Escenario 2:** Dado que existen datos de radiación registrados para los dispositivos del usuario, Cuando el usuario revisa las recomendaciones, Entonces el sistema muestra sugerencias adaptadas al nivel de riesgo detectado en cada zona. |
| US07 | Visualización de historial de alertas y acciones realizadas | Como usuario, quiero consultar un historial de alertas de radiación y acciones ejecutadas por el sistema, para hacer seguimiento del comportamiento del sistema y el estado de mis dispositivos. | **Escenario 1:** Dado que el usuario accede a la sección de historial en la app móvil, Cuando ingresa al módulo, Entonces el sistema muestra una lista cronológica de alertas con fecha, hora, nivel de radiación y acción tomada. **Escenario 2:** Dado que el usuario selecciona un evento del historial, Cuando abre el detalle, Entonces el sistema muestra información completa incluyendo dispositivos afectados, zona y acciones ejecutadas. |
| US08 | Visualización de riesgos por radiación electromagnética | Como usuario, quiero visualizar información sobre los riesgos de la exposición a radiación electromagnética, para entender cómo puede afectar mi salud y tomar precauciones. | **Escenario 1:** Dado que el usuario se encuentra en la aplicación móvil, Cuando accede a la sección informativa de riesgos, Entonces el sistema muestra contenido sobre riesgos asociados a la radiación electromagnética organizado por categorías. **Escenario 2:** Dado que el usuario visualiza la información de riesgos, Cuando navega dentro de la sección, Entonces el sistema presenta la información de forma clara, con íconos y texto comprensible para usuarios no técnicos. |
| US09 | Recomendaciones para reducir exposición a radiación | Como usuario, quiero recibir recomendaciones personalizadas para reducir mi exposición a radiación, para prevenir problemas de salud a futuro. | **Escenario 1:** Dado que existen niveles de radiación detectados en las zonas del usuario, Cuando el usuario accede a las recomendaciones, Entonces el sistema muestra sugerencias basadas en el nivel de riesgo detectado. **Escenario 2:** Dado que el usuario visualiza las recomendaciones, Cuando revisa el contenido, Entonces el sistema muestra acciones claras y realizables priorizadas por impacto en la reducción de exposición. |
| US10 | Consulta de dudas mediante chatbot | Como usuario, quiero hacer preguntas sobre radiación electromagnética mediante un chatbot, para resolver mis dudas de forma rápida e interactiva. | **Escenario 1:** Dado que el usuario accede al chatbot desde la app móvil, Cuando escribe una pregunta, Entonces el sistema procesa la consulta y genera una respuesta relevante en menos de 3 segundos. **Escenario 2:** Dado que el sistema genera una respuesta, Cuando el usuario la recibe, Entonces esta es clara, relevante y relacionada con la pregunta formulada. **Escenario 3:** Dado que el servicio de IA no está disponible, Cuando el usuario envía una pregunta, Entonces el sistema muestra un mensaje amigable indicando que el asistente no está disponible temporalmente. |
| US11 | Recomendaciones mediante chatbot | Como usuario, quiero recibir recomendaciones a través del chatbot, para mejorar mis hábitos y reducir riesgos por radiación. | **Escenario 1:** Dado que el usuario interactúa con el chatbot, Cuando solicita consejos o recomendaciones, Entonces el sistema responde con sugerencias prácticas y aplicables. **Escenario 2:** Dado que existen datos de radiación del usuario en el sistema, Cuando el chatbot responde, Entonces adapta sus recomendaciones según el contexto del usuario. |
| US12 | Dashboard Personal | Como usuario registrado, quiero tener un panel con mis métricas personalizadas para dar seguimiento a mi exposición, para poder gestionar mi exposición de manera eficiente. | **Escenario 1:** Dado que la personalización mejora la experiencia del usuario, Cuando el usuario inicia sesión en la app móvil, Entonces visualiza un resumen con nivel actual de exposición, tendencia de los últimos 7 días, alertas recibidas y estado de sensores. **Escenario 2:** Dado que el usuario es nuevo y no tiene datos registrados, Cuando accede al dashboard, Entonces el sistema muestra el panel con valores en cero y un mensaje guía para comenzar el monitoreo. |
| US13 | Registro de exposición personal | Como usuario, quiero registrar manualmente mi ubicación frecuente para hacer seguimiento personalizado, para realizar un análisis de mi exposición en función de mis ubicaciones. | **Escenario 1:** Dado que no siempre se cuenta con GPS activo, Cuando el usuario ingresa manualmente una dirección o ubicación, Entonces se vincula a su perfil para futuras mediciones y análisis. **Escenario 2:** Dado que el usuario ya tiene ubicaciones registradas, Cuando agrega una nueva ubicación, Entonces el sistema la añade a la lista y permite priorizar cuáles monitorear activamente. |
| US14 | Perfil de exposición por día | Como usuario, quiero ver un resumen diario de mi exposición EM para controlar mis hábitos, para saber cómo varía mi exposición a lo largo del tiempo. | **Escenario 1:** Dado que el control personal es importante para el usuario, Cuando revisa su panel de exposición diaria, Entonces encuentra un gráfico con la variación de niveles a lo largo del día, pico máximo y promedio. **Escenario 2:** Dado que el usuario tiene datos de múltiples días, Cuando selecciona una fecha anterior, Entonces el sistema muestra el resumen de ese día y permite compararlo visualmente con el día actual. |
| US15 | Filtrado de Datos | Como usuario, quiero filtrar por fecha, zona y tipo de fuente EM para un análisis más específico, para obtener resultados más detallados y relevantes. | **Escenario 1:** Dado que se manejan muchos datos en el sistema, Cuando el usuario selecciona filtros de fecha, Entonces el sistema muestra solo la información correspondiente al período seleccionado. **Escenario 2:** Dado que el usuario necesita un análisis específico, Cuando aplica múltiples filtros simultáneamente (fecha + zona + tipo de fuente), Entonces el sistema muestra los resultados que coinciden con todos los criterios y permite limpiar filtros individualmente. |

## 3.3. Product Backlog

Una vez definidas todas las User Stories (US), es necesario establecer su nivel de prioridad. Para ello, se utiliza el Product Backlog, en el cual las historias se organizan según su importancia y el valor que aportan al proyecto. La estimación del esfuerzo de cada historia se realiza mediante Story Points, utilizando la escala de Fibonacci (1, 2, 3, 5, 8). A medida que aumenta la puntuación, se entiende que la historia implica mayor complejidad o impacto dentro de la plataforma. En consecuencia, aquellas US con mayor puntaje suelen ser priorizadas y desarrolladas en las primeras fases del proyecto.
